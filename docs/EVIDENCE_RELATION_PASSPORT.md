# Evidence / Relation Passport

Use this compact record when one source, project or fictional motif appears relevant to another. It is a **link-testing form**, not proof that the link is causal.

## Hard surface boundary

- Keep original chats, private excerpts, identifying health/financial details and protected technical material in the authorized private source archive.
- In this public repository, record only minimized, non-sensitive summaries and stable internal source labels that do not reveal private content.
- A fictional element remains `FICTION`; it cannot be cited as factual support.
- A public analogy never authorizes copying private wording, timestamps or identity clues.

## Acceptance rule

A relation may guide work only when its source labels, surface boundary, ordinary comparator, disconfirming evidence and pass/fail test are filled. Missing fields keep it a hypothesis. Similar language, enthusiasm or repeated mention alone never upgrades evidence.
