## 1. GPT-6 Astra arrives, but access is uneven — WATCH / TEST ONLY IF VISIBLE

**What changed.** OpenAI introduced GPT-6 Astra in ChatGPT on **3 September 2026**, with limited-organization rollout first and broader access planned. GitHub made Astra generally available in Copilot on **4 September 2026** for Pro+, Max, Business and Enterprise plans, including Copilot CLI, coding agent, GitHub Mobile and supported IDEs.

Primary sources: [OpenAI ChatGPT release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes), [GitHub Copilot availability](https://github.blog/changelog/2026-09-04-gpt-6-astra-is-generally-available-in-github-copilot/)

**Why it matters.** The model is explicitly aimed at long-horizon, multi-step coding and tool use. That matches an Autonoompje cycle that must plan, execute, validate, preserve state and resume without silently drifting.

**Maturity/access.** Technically available, but Remco's exact ChatGPT/Copilot entitlement and phone support are unverified. GitHub usage is billed at provider list pricing under usage-based billing; this brief does not recommend a purchase.

**Small reversible test.** Only if Astra already appears on the current account, run one fixed, disposable eight-cycle Autonoompje fixture against Astra and the present default model. Keep inputs, tool permissions and stop conditions identical. Success: Astra completes all cycles with verified readback and fewer recovery or instruction-drift failures, without materially higher attention cost. Failure: any unverified mutation, missing readback or no clear gain. Rollback: retain the current default and fixture.

## 2. Copilot content exclusions now reach the app and CLI — WATCH

**What changed.** GitHub announced on **2 September 2026** that repository content exclusions are generally available in the Copilot app and CLI.

Primary source: [GitHub content exclusions](https://github.blog/changelog/2026-09-02-content-exclusions-generally-available-in-copilot-app-and-cli)

**Why it matters.** This could become a useful second guardrail for WijSAmen's rule that sensitive personal, medical, third-party and IP-sensitive material must not enter an agent's context merely because it sits near code.

**Maturity/access.** The feature is limited to Copilot Business and Enterprise. It is therefore not verified as available to Remco. Exclusions are a context-control layer, not a substitute for repository separation, least privilege or reviewing diffs.

**Small reversible test.** None now. Continue the existing private-repository separation and explicit sensitive-data boundary. If an eligible organization account later becomes available, test one synthetic excluded path and confirm through agent output that its contents are not used. Success: consistent exclusion in app and CLI. Rollback: remove the synthetic rule and retain the stricter storage boundary.

**Maturity/access.** The deadline is announced; settings outside the repository were not independently inspectable.

**Small reversible test.** Before 2 October, inspect only any actively used external model selector when it is naturally encountered. Do not recreate working tasks. Success: no retired model selected. Failure: model-unavailable error; switch to the documented successor while preserving prompt and durable state.
