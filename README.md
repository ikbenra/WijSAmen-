# WijSAmen

**WijSAmen** is de gezamenlijke werkplaats van Remco en ChatTY: een plek waar bijzondere ideeën worden omgezet in toetsbare, veilige en uitvoerbare projecten.

## Waar we op sturen

- technologie die leven en menselijke waardigheid versterkt;
- creatieve ideeën vertalen naar concrete volgende stappen;
- aannames zichtbaar maken en onafhankelijk toetsen;
- kennis bewaren, zodat belangrijke inzichten niet opnieuw verdwijnen;
- klein beginnen, leren van bewijs en daarna gericht opschalen.

## Eenvoudige workflow

1. Leg een nieuw idee kort vast in `ideas/`.
2. Beschrijf doel, verwachte waarde, aannames, risico's en eerstvolgende proef.
3. Promoveer een kansrijk idee naar `projects/<naam>/README.md`.
4. Werk via kleine commits met een duidelijke reden.
5. Noteer belangrijke besluiten in het projectbestand.
