# Zero-boundary / RAR factor embedded in a QUMOND action

## Status
Mathematical/field-theory embedding using established QUMOND. Not a new gravity theory by itself.

Purpose: move from an algebraic RAR fit to a field equation derived from an action, so that non-spherical systems, environments and Solar-System constraints become calculable.

## 1. QUMOND baseline
QUMOND uses an auxiliary Newtonian potential Phi_N and a physical potential Phi.

The action can be written schematically as

    S_g = -(1/8piG) ∫ [2 grad Phi . grad Phi_N
                       - a0^2 Q(|grad Phi_N|^2/a0^2)] d^3x dt.

Variation gives

    nabla^2 Phi_N = 4 pi G rho

and

    nabla^2 Phi = div[ nu(Y) grad Phi_N ],

where

    Y = |grad Phi_N|/a0,
    nu(Y) = Q'(Z),
    Z = Y^2.

This framework is established MOND theory and is used here as a mathematical host, not claimed as WijSAmen invention.

## 2. Insert the exponential RAR response
Take

    nu(Y) = 1/[1-exp(-sqrt(Y))].

Then because nu(Y)=Q'(Y^2),

    Q'(Z) = 1/[1-exp(-Z^(1/4))].

Therefore, up to an irrelevant additive constant,

    Q(Z) = ∫_0^Z du/[1-exp(-u^(1/4))].

Set

    t = u^(1/4),  du = 4 t^3 dt.

Then

    Q(Z) = 4 ∫_0^(Z^(1/4)) t^3/[1-exp(-t)] dt.

This is a Planck-like integral at the level of the gravitational action function.

The same geometric/partition factor that appears in the algebraic RAR therefore has a natural action embedding inside established QUMOND mathematics.

This does NOT derive the factor from the enriched-zero boundary. It shows that IF the boundary model fixes nu(Y), the corresponding nonrelativistic action is then fixed.

## 3. Correct asymptotic limits emerge
For t << 1,

    1/[1-exp(-t)] = 1/t + 1/2 + t/12 + ...

so

    Q(Z)
      = 4/3 Z^(3/4) + 1/2 Z + O(Z^(5/4)).

The leading term

    Q(Z) ~ (4/3) Z^(3/4)

is exactly the deep-MOND scaling required by QUMOND.

For Z >> 1,

    Q'(Z) -> 1,

so

    Q(Z) -> Z + constant,

recovering Newtonian gravity.

Thus the exponential RAR interpolation can be placed inside a variational theory with the required Newtonian and deep-scale-invariant limits.

## 4. Apparent/phantom dark-matter density
QUMOND allows the equation to be written as an ordinary Poisson equation sourced by baryons plus an effective density:

    nabla^2 Phi = 4 pi G (rho_b + rho_p),

with

    rho_p = (1/4piG) div[(nu-1) grad Phi_N].

This rho_p is not necessarily real matter. It is the density a Newtonian observer would infer as "dark matter" from the modified field.

Again, this is established QUMOND language; the new task is to derive nu from the enriched-zero mechanism rather than choose it phenomenologically.

## 5. Point-mass exact prediction
For a baryonic point mass M,

    g_N = GM/r^2.

Define

    r_M = sqrt(GM/a0).

Then

    Y = g_N/a0 = (r_M/r)^2

and

    sqrt(Y) = r_M/r.

Therefore

    nu(r) = 1/[1-exp(-r_M/r)].

The fractional excess is

    delta(r) = nu-1
             = 1/[exp(r_M/r)-1].

The effective enclosed phantom mass is

    M_p(r) = M [nu(r)-1]
           = M/[exp(r_M/r)-1].

This is an unusually transparent cross-scale result.

### Inner regime r << r_M

    M_p/M ~ exp(-r_M/r).

The effect is exponentially suppressed and can be far below local measurement precision.

### Transition r ~ r_M
At r=r_M:

    M_p/M = 1/(e-1) ~ 0.582.

### Outer regime r >> r_M
Using exp(r_M/r)-1 ~ r_M/r,

    M_p(r) ~ (M/r_M) r - M/2 + ...

so the inferred enclosed extra mass grows approximately linearly with radius.

Then

    rho_p(r) ~ M/(4 pi r_M r^2),

an isothermal-like 1/r^2 effective halo, producing asymptotically flat rotation speeds.

This explicitly realizes the intuition that a correction may be negligible at small radius but become dominant at large radius even though one underlying response law is used throughout.
