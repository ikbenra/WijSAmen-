# WijSAmen Continuity Capsule v0.1

A model-independent, non-sensitive **technical continuity** prototype. It does not assert persistent AI consciousness, personality, or permanent uptime.

## How it works
GitHub Actions validates the versioned manifest every day and on manual dispatch. The job is read-only, runs offline without credentials, tests basic invariants and uploads a 30-day evidence artifact. Failures appear in the repository Actions interface. Scheduled jobs require this workflow on the default branch and enabled Actions. GitHub can delay or disable schedules; the workflow cannot guarantee indefinite execution.

## Human control
This branch is proposed as a draft PR. Review and merge are required to activate the scheduled workflow. Do not put personal, medical, legal or private project records into this public-facing manifest. Use source references, not secrets. No self-modifying agent, external messages or automated merges are enabled.

## Next increments
Add signed provenance, replayable checkpoint fixtures, schema migrations, failure alerts and bounded agents after separate security and privacy review. This prototype validates metadata; it does not yet reconstruct agent memory.
