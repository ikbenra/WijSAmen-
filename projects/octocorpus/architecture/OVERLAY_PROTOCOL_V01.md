under a B context compared with the frozen checkpoint policy and restores exact
pre-overlay actions after retirement. A permanent-update comparator receives the
same fitted rule. Its return-to-A result quantifies interference.

test observations from seed+100000. Noise is uniform [-0.15,0.15] around eight
latent binary patterns. A uses a preregistered explicit truth table. B reverses
its action labels. Models are linear threshold rules. Search considers 875 rules
from weights -2..2 and thresholds -2..4; ties prefer small L1 norm, then a stable
lexicographic rule. Calibration only selects weights. The original checkpoint
is checked before use. Shuffled calibration labels provide a negative control.

zero behavioral mismatches after retirement, including re-query in context B.
Report per-group means and paired seed delta ranges. A/B/return phases reuse
the same final inputs for paired behavioral comparisons. Seeds vary amplitude
noise, not task semantics or independent learned architectures. Once seen, the
test is regression data. No score-dependent tuning within this run.
