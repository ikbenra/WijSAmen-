# Neumann Mission Core

Experimental open-source mathematics kernel for **Neumann missie software uitwerking**.

## Purpose

Study exact rational expansions, long-division remainder states and carry operations as a foundation for testing the proposed binary → decimal → hexadecimal rotation. The connection to autonomous von Neumann probe fleets is **a research hypothesis**, not a proven mission-control capability.

## Current scope

The local v0.1 prototype contains Python modules for exact base expansions, carry primitives and unit tests. This branch establishes the project directory. Further source files will be committed separately after review and verification.

## Next steps

1. Formalize base-independent remainder/phase alignment.
2. Specify carry-triggered transitions, overlap and adaptive group sizes.
3. Test against fixed-base controls.
4. Build a simulation-only probe-task coordinator with audit logs.
